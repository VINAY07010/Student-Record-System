# 📚 Student Record System (C++)

A simple **console-based student management system** built in C++.  
This project demonstrates file handling, object-oriented programming, and data operations like **add**, **view**, **search**, **update**, **delete**, **sort**, and **export to CSV**.

---

### 🧰 Features

| Feature               | Description                                                     |
|------------------------|-----------------------------------------------------------------|
| ➕ Add Student          | Add a new student's ID, roll number, name, gender, course, year, and CGPA |
| 📄 View All Students    | Display all stored student records                             |
| 🔍 Search by Roll No    | Find and display a student by their roll number                |
| 📝 Update Record        | Modify a student's information                                 |
| ❌ Delete Record        | Remove a student record based on roll number                   |
| ✅ Input Validation     | Ensures valid data (e.g. non-empty name, CGPA between 0-10)     |
| 📂 Export to CSV        | Export all records to a clean `students.csv` file              |
| 📊 Sort Records         | Sort students by roll number, name, or CGPA                    |
| 💾 Binary File Storage  | Efficient internal binary `.dat` storage for fast access       |

---

### 🔧 Technologies Used

- **C++**: Core language for building the student management system.
- **File Handling**: For data storage in `.dat` and `.csv` files.
- **Object-Oriented Programming (OOP)**: Utilized for defining the `Student` class and its attributes and methods.
- **STL (Standard Template Library)**: For vector storage and sorting functionality.
